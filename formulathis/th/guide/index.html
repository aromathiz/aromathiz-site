คู่มือ

f(x) = x² − 4x + 3, x ∈ [0, 4]

ด้วย formulaThis เอกสารเดียวสามารถรวมข้อความ สูตร ตาราง และรูปเรขาคณิตไว้ด้วยกัน คู่มือนี้อธิบายบล็อกแต่ละชนิดและการส่งออก

บล็อกข้อความ

แตะไอคอน “แทรกบล็อกข้อความ” เพื่อเขียนโจทย์หรือคำอธิบาย หากต้องการแทรกสูตรกลางประโยค ให้แตะ “แทรกสูตร” สูตรจะแสดงในข้อความทันที

ให้ f นิยามบน [0, 4] โดย f(x) = x² − 4x + 3 จงศึกษาการเปลี่ยนแปลงของ f

บล็อกสูตร

แตะ “แทรกบล็อกสูตร” สูตรเขียนด้วย LaTeX แต่คุณไม่จำเป็นต้องรู้ไวยากรณ์ ปุ่มบนแถบเครื่องมือช่วยให้สร้างสูตรได้ทีละขั้น

f′(x) = 2x − 4
f′(x) > 0 ⇔ x > 2
