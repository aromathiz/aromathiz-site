Créer des formules mathématiques simplement

Découvrez comment utiliser formulaThis pour créer vos formules avec l'éditeur visuel ou avec du code LaTeX, puis les exporter facilement.

Créer une formule en quelques étapes

formulaThis vous permet de construire des formules mathématiques directement depuis votre téléphone.

ÉTAPE 1

Saisissez

Utilisez l'éditeur visuel et ses boutons dédiés pour construire votre formule.

ÉTAPE 2

Visualisez

Le rendu de votre formule apparaît instantanément à l'écran.

ÉTAPE 3

Exportez

Exportez votre formule en PNG ou PDF, ou copiez-la dans le presse-papiers.

Vous connaissez LaTeX ?

Vous pouvez également saisir directement votre code LaTeX et visualiser immédiatement le résultat.

\frac{-b+\sqrt{b^2-4ac}}{2a}
\span> \(\frac{-b+\sqrt{b^2-4ac}}{2a}\)

Exportez vos formules

Une fois votre formule créée, utilisez-la où vous en avez besoin.

PNG Exportez votre formule sous forme d'image.
Copier Copiez votre formule dans le presse-papiers.
PDF Créez un document PDF contenant votre formule.
