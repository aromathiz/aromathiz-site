01 — THE CODE

Writing a square root in LaTeX

In LaTeX, the \sqrt command creates a square root. It takes a single expression: the one placed under the root. For an nth root, add the index in square brackets.

Square root
\sqrt{x}
nth root
\sqrt[n]{x}
02 — IN FORMULATHIS

03 — A FEW EXAMPLES

From simple roots to complex formulas

The \sqrt command works with numbers, variables or more complex mathematical expressions, and it can even be nested.

Simple root
2
\sqrt{2}
Cube root
x3
\sqrt[3]{x}
Expression under the root
x2 + y2
\sqrt{x^2+y^2}
Nested roots
1+ 2
\sqrt{1+\sqrt{2}}
