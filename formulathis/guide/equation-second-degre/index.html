Écrire une équation du second degré en LaTeX.

Découvrez comment écrire l'équation, le discriminant et les solutions d'un polynôme du second degré en LaTeX, les visualiser instantanément dans formulaThis et les exporter en image ou en PDF.

Équation du second degré créée avec formulaThis
01 — LE CODE

Écrire l'équation en LaTeX

Une équation du second degré s'écrit sous la forme ax² + bx + c = 0. En LaTeX, l'exposant s'obtient avec le symbole ^ : x^2 donne x². Pour un exposant de plusieurs caractères, utilisez des accolades, par exemple x^{10}.

Code LaTeX
ax^2 + bx + c = 0
02 — DANS FORMULATHIS

Créez votre équation avec formulaThis

Ouvrez formulaThis et saisissez directement votre code LaTeX dans l'éditeur. Le rendu de la formule apparaît immédiatement à l'écran, ce qui permet de corriger une accolade oubliée sans attendre la compilation d'un document.

Astuce : vous pouvez également utiliser l'éditeur visuel et ses raccourcis mathématiques pour construire votre formule sans avoir à mémoriser les commandes LaTeX.
03 — QUELQUES EXEMPLES

De l'équation à ses solutions

Pour résoudre une équation du second degré, on calcule le discriminant Δ, puis les solutions. Voici le code de chaque étape.

L'équation
ax2 +bx +c=0
ax^2 + bx + c = 0
Le discriminant
Δ= b2 −4ac
\Delta = b^2 - 4ac
Les solutions
x= −b± Δ 2a
x = \frac{-b \pm \sqrt{\Delta}}{2a}
Les deux racines
x1= −b− Δ 2a
x_1 = \frac{-b - \sqrt{\Delta}}{2a}
04 — LES TROIS CAS

Écrire les cas du discriminant

Le signe de Δ détermine le nombre de solutions réelles. Les symboles >, = et < s'écrivent tels quels en LaTeX.

Δ > 0

Deux solutions réelles distinctes.

\Delta > 0

Δ = 0

Une solution double, égale à −b / 2a.

x_0 = -\frac{b}{2a}

Δ < 0

Aucune solution réelle.

\Delta < 0
