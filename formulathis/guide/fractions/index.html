01 — LE CODE

Écrire une fraction en LaTeX

En LaTeX, la commande \frac permet de créer une fraction. Elle prend deux éléments : le numérateur et le dénominateur.

Code LaTeX
\frac{a}{b}
```
```
02 — DANS FORMULATHIS

Créez votre fraction avec formulaThis

Ouvrez formulaThis et saisissez directement votre code LaTeX dans l'éditeur. Le rendu de la formule apparaît immédiatement à l'écran.

Astuce : vous pouvez également utiliser l'éditeur visuel et ses raccourcis mathématiques pour construire votre formule sans avoir à mémoriser les commandes LaTeX.

03 — QUELQUES EXEMPLES

Des fractions simples aux formules complexes

La commande \frac peut être utilisée avec des nombres, des variables ou des expressions mathématiques plus complexes.

Fraction simple
½
\frac{1}{2}
Avec des variables
x + 1
─────
x − 2
\frac{x+1}{x-2}
Formule complexe
−b ± √(b² − 4ac)
─────────────
2a
\frac{-b \pm \sqrt{b^2-4ac}}{2a}
```
